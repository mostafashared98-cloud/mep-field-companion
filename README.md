# MEP Field Companion (Offline PWA — V1.3)

تطبيق ويب أوفلاين (PWA) مخصص لمهندس الميكانيكا (الموقع والمكتب الفني).

## الملفات
- `index.html`: التطبيق الكامل أوفلاين 100%.
- `manifest.json`: إعدادات تثبيت التطبيق على شاشة الموبايل (`Add to Home Screen`).
- `sw.js`: محرك العمل الأوفلاين (Service Worker).
- `icon-192.png` و `icon-512.png`: أيقونات التطبيق.
